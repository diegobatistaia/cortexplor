OpenAI Acquires Developer Startup Pierre Computer for Codex

The deal folds Pierre's code-storage technology into OpenAI's Codex tool and is widely read as a move to cut reliance on Microsoft's GitHub.

Newsroom Cortexplor Checked against 3 sources

OpenAI announced plans to acquire Pierre Computer Company, a developer tooling startup founded in 2024, according to the company's own statement, as reported by SiliconANGLE and Brazil's Tecmundo/Estadão. The terms of the deal were not disclosed.

Pierre runs a code-storage service built for AI coding agents, along with open-source libraries called Trees and Diffs that already power parts of the interface in Codex, OpenAI's programming tool, SiliconANGLE reported. OpenAI said it will fold Pierre's storage service into Codex and keep the Trees and Diffs libraries open source after the deal closes, according to both SiliconANGLE and Tecmundo/Estadão.

SiliconANGLE explained that large software projects can contain hundreds of code files organized across dozens of folders, and that many programming tools include a sidebar meant to help developers navigate them — the exact problem Trees was built to solve before it was folded into Codex. The same outlet reported that Trees adds a search feature and drag-and-drop controls for moving subfolders to that sidebar, while also flagging files that were recently added or updated. Diffs, the other library, shows line by line what changed in a code file after an edit, and can display those changes either in a separate section of the interface or inline, according to SiliconANGLE.

Neither OpenAI nor Pierre said when the transaction is expected to close. Both SiliconANGLE and Tecmundo/Estadão describe the deal as still in progress, not yet finalized. The two outlets also agree that the Pierre deal and the Pando rollout both sit within the same push: building more of the infrastructure behind Codex in-house instead of relying on outside services.

Tecmundo/Estadão reports a clear split in roles going forward: Pierre's Code Storage technology will operate at the infrastructure layer, handling the storing, reviewing and serving of code, while Codex keeps handling the actual development work.

Less reliance on GitHub

The acquisition is widely read as an attempt by OpenAI to reduce its dependence on GitHub, the code-hosting service owned by Microsoft, according to both SiliconANGLE and Tecmundo/Estadão. The two companies already had a technology-sharing partnership before the acquisition was announced.

The move comes days after OpenAI unveiled Pando, an internal system for organizing Git repositories that the company says cuts the time its own coding agents need to create and read files, as reported by both outlets.

SiliconANGLE also reported that OpenAI says Pierre's team will, in the longer term, help the company ship new products and platforms, with an emphasis on software that optimizes coding agents and streamlines their work with Git, the version-control tool OpenAI uses extensively in-house.

Tecmundo/Estadão notes that control over this chain, from code storage to the programming tool itself, is seen as strategic in a coding-agent market that already includes rivals such as Anthropic's Claude Code and Cursor, the latter integrated with xAI's Grok.

SiliconANGLE reported that Pierre itself claims to have helped generative AI startup Lovable cut code retrieval time by about 70% using its storage service. Tecmundo/Estadão reported that the startup currently employs about 15 developers. SiliconANGLE also said Trees' feature for flagging recently changed files helps developers figure out where to start when investigating a problem, such as an outage.

In practice

  • The Pierre acquisition does not add any new feature for current Codex users yet; integration of the code-storage service is planned for 2027, according to Tecmundo/Estadão.
  • The open-source Trees and Diffs libraries, already used in Codex's interface, remain available under an open license, according to OpenAI and SiliconANGLE.
  • The price OpenAI is paying for Pierre has not been disclosed.
  • The deal adds to OpenAI's push to rely less on Microsoft's GitHub for storing and organizing code generated by AI agents.
