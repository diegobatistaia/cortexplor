Anthropic launches Claude Ship to review, fix and approve code.

According to TechCrunch and The Verge, Claude Ship is a set of agents that reviews, fixes and can approve pull requests without a person at every stage. The new beta pieces are PR Steward, which fixes failing checks and merge conflicts, and Claude Approvals, which clears routine changes under a policy the team sets (ZDNet).

TechRadar says review became the bottleneck as AI writes so much code. Each team decides which repositories run Claude Ship and what still needs a person. ZDNet's David Gewirtz says shipping code at the pace it is written raises the hair on his neck, and flags a risk to how junior developers learn.
