Claude Haiku 5.5 launched with API prices up to 90% lower on short prompts, according to Olhar Digital.

Canaltech describes the model as built for repetitive, cost-sensitive tasks such as summarization, classification and database queries. It can also run as a coding sub-agent beside Opus 5.5 and Sonnet 5.5.

Anthropic's documentation, cited by Olhar Digital, lists a one-million-token context window. Haiku 5.5 is the first Haiku-tier model with adjustable effort levels, which set how much reasoning it applies before answering (Olhar Digital, Canaltech).
